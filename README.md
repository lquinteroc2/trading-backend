# Trading Backend

API y servicios de backend para la plataforma de trading.

## Estado

Repositorio inicial. La implementacion del backend esta pendiente de definir.

## Objetivo

Este proyecto contendra la logica de negocio, autenticacion, integraciones con datos de mercado, persistencia y endpoints consumidos por las aplicaciones web y mobile.

## Estructura prevista

- `src/`: codigo fuente de la API y servicios.
- `tests/`: pruebas automatizadas.
- `docs/`: documentacion tecnica adicional.
- `config/`: configuracion por ambiente cuando aplique.

## Desarrollo

Cuando el stack este definido, documentar aqui:

- Requisitos de instalacion.
- Variables de entorno.
- Comando para ejecutar en local.
- Comando para correr pruebas.
- Comando para generar build o artefactos.

## Flujo de ramas

- `main`: rama estable.
- `develop`: rama de integracion para desarrollo.
- `feature/*`: ramas para nuevas funcionalidades.
